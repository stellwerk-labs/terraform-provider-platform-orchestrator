# Terraform/OpenTofu provider v2.2.0-rc.1

Prerelease for testing Module authoring with the coordinated CP 3.2, DP 4.1
and gateway changes.

## Draft authoring and execution

The `platform-orchestrator_module_draft` resource manages editable Drafts with
retained revisions. Its `authoring_key` makes creation retry-safe. Publication
freezes the reviewed revision as a separate immutable Proposed Version and
closes the Draft. Create another Draft to continue authoring after publication.
Destroy closes an open Draft while retaining its history.

The `platform-orchestrator_module_draft_test` resource captures an immutable
snapshot. Select it explicitly through a deployment's `draft_test_snapshots`.
Saving or editing a Draft does not capture or deploy a test. Editing preserves
the Draft identity, earlier snapshots and deployment results. Unchanged reviewed
configuration produces an empty plan.

Resource Types retain their identity and gain immutable, consecutive interface
versions. New data sources expose exact interfaces and history. Importing a
Module Version preserves its selected interface in provider state; existing
Versions and Pins keep their original binding.

## Compatibility

Use matching server APIs and gateway routes. Older servers that lack a requested
endpoint return a clear error. An explicit Draft test never falls back to the
ordinary deployment path or a published Default.

Generated clients are pinned to public CP and DP sources and pass the normal
public-source checks. Final packaged upgrade and plugin compatibility checks
remain part of the coordinated release qualification. Back up state and review
the plan before applying a provider upgrade.
