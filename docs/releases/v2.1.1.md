# Orchestrator Terraform/OpenTofu provider v2.1.1

This maintenance release updates the Go toolchain, dependencies and generated
clients. Resource schemas, state ownership and deployment behaviour retain
their v2.1.0 contracts.

## Security and compatibility

Official builds use Go 1.26.10, including the certificate verification fix for
[CVE-2026-111943](https://pkg.go.dev/vuln/GO-2026-6809). HTTP, cryptography,
OpenAPI and gRPC dependencies are updated. Generated clients use the corrected
server contracts without changing API wire values. Normal CI checks source
dependencies and release payloads for reachable known vulnerabilities.

The contained acceptance job selects every `TestAcc...Local` case, including
all-organization enablement. The separate server-backed acceptance job retains
its own disposable-organization and credential requirements.

The coordinated application patch set is Control Plane 3.1.1, Data Plane 4.0.1,
IAM 2.5.1 and Console 1.4.1. Exact published server source pins are verified
before client publication.

## Upgrade and distribution

Select provider version 2.1.1 in Terraform or OpenTofu. The registries index
releases independently; verify the version and signed download in the registry
you use. A GitHub release alone does not establish registry availability.
Back up state and configuration, refresh and inspect the plan before applying.
This patch requires no state or server database migration.

The provider update does not update the Runner's bundled OpenTofu, the plugin
runtime or external services. Their separate security holds remain in effect.
